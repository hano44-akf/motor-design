# SPM 리플 모듈과 첫 검증 범위

사용자 지시에 따라 SPM은 Surface Radial·Parallel·Breadloaf·Flat 네 가지 전체다. 향후 IPM은 설치된 Motor-CAD의 Inset·Embedded·Interior 타입 전체를 대조해 포함하고 Spoke는 별도 모듈로 관리한다. 일부 형상의 성공을 전체 SPM/IPM 성공으로 표시하지 않는다.

## 구현

`spm_ripple.py`는 네 형상의 실제 자석 경계를 공통 입력으로 받는 실험용 자기회로 모델이다. Native line/arc 경계와 방사선 교점으로 자석 두께·공극 프로파일을 만들고, 슬롯 위치별 근사 퍼미언스와 실제 권선 배치로 다음 에너지 함수를 구성한다.

W'(α,i)=W'pm(α)+ψpm(α)ᵀi+0.5 iᵀL(α)i

T(α,i)=∂W'pm/∂α+iᵀ∂ψpm/∂α+0.5 iᵀ(∂L/∂α)i

전류를 고정한 편미분을 사용하며, 회전자와 함께 변하는 전류까지 미분하지 않는다. 기계각 라디안으로 Fourier 미분하고 평균·최대·최소 토크로 피크투피크/절대 평균 리플을 계산한다. 무부하 평균0 부근에서는 비율을 만들지 않는다. Delta 선전류 첨두를 sqrt(3)으로 나누어 상전류 첨두로 사용한다.

**이 구현은 논문의 정확한 서브도메인 해법을 재현한 것이 아니다.** 방사 방향 자기회로·슬롯 프린징의 근사식이며 철심 포화·누설·접선 자화·단부·PWM·순환전류를 충분히 해석하지 않는다. 1.4T/μr1.05는 이 시험의 고정 자석값이고 재료 변경을 검증한 것이 아니다. 네 형상에서 계산 가능하다는 것과 신뢰할 수 있다는 것을 구분한다. 임의의 리플 보정계수, 값 제한, 목표 맞춤 스케일링은 없다.

## 검증

`validate_spm_ripple.py`가 후보16개×4형상의 Native 경계를 추출한다. Flat은 실제 Native 경계가 직선으로만 구성되는지도 확인한다. 저장·재로딩 값, 권선 균형 및 Native 재료를 대조한다. 각 형상에서 예측 리플이 낮은2개를 미리 고정한 뒤 최대8회 FEA를 실행한다. 후보 생성은 Sobol 표본이며 전 조합 스윕이나 연속 최적화 완료로 부르지 않는다.

선택·예측 파일은 FEA 전에 고정한다. 이 데이터를 보정에 쓴 뒤 같은 사례를 새 독립 검증이라고 주장하지 않는다. 예측20% 이하 후보가 없으면 낮은2개의 해석은 진단용이며 해당 형상의 인수 기준은 통과가 아니다.

첫 검증은 D85×L20, 4극12슬롯, Delta, 6턴, 도선1.8mm, 20℃, 3500rpm, 선전류첨두40A, Id=0 기준이다. 외부 형상·극슬롯·전류·온도 전체로 확장하지 않는다. 치 폭8.1mm/슬롯 깊이8.8mm를 고정하고 슬롯 입구·자석 두께·공극·극호 또는 Flat 너비·Breadloaf reduction을 탐색한다. 최소 코너 제조 기준과 전체 자기 적합성은 FEA 성공만으로 인증하지 않는다.

사용자 기준은 **예측≤20%, 별도 FEA≤50%**다. 형상별 선택 후보를 각각 passed/failed/unverified/not_tested로 기록한다. 이 기준 통과는 실제20% 만족 인증이나 전체 형상군 정확도 보장이 아니다. 원시 파형과 Native 리플값을 보존한다. 기존 생산용 Breadloaf·Flat 매핑 차단은 해제하지 않는다.

실행은 새 인스턴스와 별도 재료DB·출력 폴더를 사용하고 전역 잠금으로 직렬화한다. 기존 열린 Motor-CAD 창을 조작하지 않는다. 오류·진행·부분 결과를 기록하고 FEA 실패 자동 재시도는 하지 않는다. 열·구조·스큐 해석은 제외한다.

## 아직 완료되지 않은 기능

기존 생산 최적화 엔진에 리플 지표가 연결된 것은 아니다. 첫 독립검증 결과를 확인한 후, 유효할 때만 벌점 항으로 연결한다. 실험용 모델의 수렴·순위 재현·포화 영역 오차도 별도 평가해야 한다. IPM 물리 계산 모듈은 아직 구현되지 않았다.

## 2026-11-04 후속 상태

사용자 지시로 Flat 리플 모델 개선·추가 해석은 보류한다. 등록 타입과 기존 결과를 삭제하지 않으며 검증 완료로 표시하지 않는다. 형상별 개발 상태는 `spm_ripple_development_policy.json`을 따른다.

Breadloaf 후속 개발로 `spm_ripple_operating_point.py`에 원시 선형 coenergy 성분의 전류 배율 C+sM+s²R과 목표 전자기 토크의 전류 역산을 추가했다. Id=0·동일 형상·온도·상대 위상 조건이며 포화와 전압은 검증하지 않는다. 같은 목표 토크에서 리플을 비교하기 위한 개발 기능이다. `outputs/breadloaf_current_matching_20261104/REVIEW_KO.md`에 5개 저장 형상의 점검 결과를 기록했다. 신규 FEA는 없다.
