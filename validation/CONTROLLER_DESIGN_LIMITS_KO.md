# 제어기 조건과 설계 제한

스위칭 주파수 입력 단위는 kHz이며 공란이면 10 kHz를 적용합니다. Python 요청·CSV는 Hz로 저장합니다. 이 값은 PWM 반송 주기의 빈도이며 트랜지스터 스위칭 에지 수나 6 STEP 정류 빈도가 아닙니다.

전기 주파수 fe = P·n/120, 전기 1주기당 PWM 주기 수 N = fs/fe입니다. P는 전체 극수, n은 rpm입니다. N >= 20만 허용하므로 최대 짝수 극수는 다음과 같습니다.

Pmax = 2·floor(60·fs/(20·n))

10 kHz, 3500 rpm에서는 16극까지 허용합니다. 4극은 85.714회, 16극은 21.429회, 18극은 19.048회입니다. 여러 운전점이 있으면 공통으로 만족하는 가장 작은 극수 상한을 사용합니다. 현재 실제 자동 실행기는 4극·12슬롯만 연결되어 있으며, 이 4극이 조건을 위반하면 Motor-CAD 실행 전에 차단합니다.

토크 리플은 Motor-CAD의 `Torque Ripple (MsVw) [%]` 결과를 사용해 20% 이하로 판정합니다. 입력은 0~20%이며 공란은 20%입니다. 20%는 포함하고 초과는 목표 미달입니다. 목표 미달 후보를 반환할 때도 합격으로 표시하지 않습니다. 이 리플은 평균 전자기 토크 대비 (최대−최소) 토크이며 PWM 전류 리플과 구분합니다. 현재 정현파 전류 지정 해석에는 PWM 스위칭으로 추가되는 토크 리플이 포함되지 않습니다.

## 인덕턴스 범위

고정된 µH 범위를 모든 설계에 일괄 적용하지 않습니다.

- 하한: 허용 PWM 전류 리플을 만족하는 최소 고주파 미분 인덕턴스.
- 상한: 요구 속도·토크에서 기본파 전압 한계를 만족하는 운전점 Lq.
- 전류 지령 변화 시간까지 제한하려면 전류 제어 대역폭과 전압 여유를 추가로 검토합니다.

FOC Id=0에서 상 RMS 값으로 쓴 전압 예산은 다음과 같습니다.

Vphase² = (Ephase + Rphase·Iphase)² + (ωe·Lq·Iphase)²

따라서 Lq,max = sqrt(Vphase,limit² − (Ephase + Rphase·Iphase)²) / (ωe·Iphase)입니다. 제곱근 내부가 양수가 아니면 유도성 전압 여유가 없습니다. E는 기본파 역기전력입니다. 프로그램은 SVPWM에서 Delta 상 RMS 한도 Vdc/√2, Y 상 RMS 한도 Vdc/√6에 0.94를 곱한 참고 상한을 표시합니다. 전압 고조파와 실제 인버터 손실을 완전히 검증한 값은 아닙니다.

PWM 리플의 기본 관계는 Ldiff·di/dt = vPWM − R·i − e입니다. 빠른 PWM 주기 안에서 평균 운전 상태를 고정하는 근사에서는 다음과 같이 표현할 수 있습니다.

Lmin ≈ kPWM·Vdc / (fs·ΔIpp,allow)

kPWM는 PWM 방식·변조지수·회전자 전기각·결선에 따라 달라지므로 공통 상수로 고정하지 않습니다. 허용 전류 리플이 지정되지 않았고 실제 PWM 파형 모델도 아직 연결하지 않았으므로 프로그램의 인덕턴스 하한은 미확정입니다. 초기 검토값으로 ΔIpp/상 기본파 첨두전류 = 20%를 제안할 수 있지만, 현재 강제 조건으로 적용하지 않았습니다. 포화 상태의 미분 인덕턴스와 Delta 순환전류를 포함해 검증해야 합니다.

현재 추가된 스위칭 주파수는 극수 적격성 검사와 결과 참고값에 사용합니다. Motor-CAD의 스위칭 파형·PWM 손실 계산을 활성화한 기능은 아닙니다.

## 추가로 제한할 항목

| 항목 | 제한 방법 | 현재 상태 |
|---|---|---|
| 상·선 전류 RMS/첨두, DC 전류 | 인버터·전원·배선 정격에 맞춤 | DC 전류 목표는 입력·판정 가능, 상/선 전류 하드웨어 정격은 추가 연결 필요 |
| 권선 전류밀도 | 연속/단시간 운전과 냉각 조건에 맞춤 | 입력·판정 가능 |
| 권선·자석 온도 | 절연 시스템과 제조사 온도별 곡선 기준 | 지정 온도별 전자기 해석 가능, 열평형 제한은 후속 필요 |
| 감자 여유 | 최고 자석 온도와 최대 역자계·고장전류에서 검사 | 감자 해석 연결 필요 |
| 포화·철손 | 재질 B-H와 주파수별 철손 데이터로 판정 | 자속밀도 출력 가능, 재질별 허용 기준과 고주파 데이터 검증 필요 |
| 슬롯 충전율·최소 공극·제조 선경 | 권선 방식과 제조 공차 기준 | 충전율·슬롯 입구 선경 검사만 연결, 제조 표준 선경·공차 추가 필요 |
| 최고 속도·회전자 응력·자석 유지력 | 기계적 허용 속도와 오버스피드 조건 | 구조 해석 연결 필요 |
| 전압 여유·극수/PWM 비율·토크 리플 | 지정 운전점에서 동시에 검사 | 현재 연결 |

전류밀도·온도·감자·포화·응력에 임의의 공통 숫자를 넣어 합격시키지 않습니다. 값이 없거나 검증 기능이 없으면 미검증으로 표시해야 합니다.
