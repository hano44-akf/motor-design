# Motor Design Studio

Python 기반 모터 초기 설계·최적화 및 선택 후보의 Ansys Motor-CAD 검증 도구입니다. 로컬 웹 인터페이스를 제공하며 계산에 AI 서비스 연결을 요구하지 않습니다.

## 구조

- `interface/`: 로컬 HTTP 서버, 입력·결과 비교 화면, 브라우저 흐름 검사.
- `validation/`: 수식 최적화, 형상·권선·제어 모델, 요구사항 판정, Motor-CAD 연결, 검증 큐 및 테스트.
- 루트 Python 파일: 재질 추출·정규화·검증 도구.
- `PROGRAM_SCOPE_KO.md`: 현재 개발·검증 범위.

## 실행

개발 환경은 Windows이며 Python 3.14에서 검사를 수행했습니다. Python 의존성과 Ansys Motor-CAD Python API가 설치된 환경에서 프로젝트 루트에서 실행합니다.

```powershell
python interface/server.py
```

브라우저에서 `http://127.0.0.1:8765`에 접속합니다. 현재 코드는 Windows 경로와 특정 설치 환경을 참조하는 곳이 있어 다른 PC에서는 경로 점검이 필요합니다. 외부 공개 서버 배포를 전제로 만든 서비스가 아닙니다.

```powershell
python -m unittest discover -s validation -p "test_*.py"
```

일부 테스트와 수식 엔진은 로컬에 저장된 기준 해석 JSON, 재질 DB 및 검증 자료를 사용합니다. 따라서 소스만 복제한 새 PC에서 전체 테스트·기준 해석 기반 계산이 즉시 실행되는 배포 패키지는 아닙니다. 실제 Motor-CAD 실행에는 해당 소프트웨어 설치와 유효한 라이선스가 필요합니다.

## 설계 흐름과 한계

요구조건 입력 → 수식 기반 후보 최적화 → 후보 비교·제외 → 선택 후보의 Motor-CAD 해석 → 조건별 재판정·CSV 내보내기 순서입니다. 양의 토크 여유율은 정격 목표를 바꾸지 않고 별도 여유 토크점으로 검증합니다.

수식 예측, 모의 테스트 통과, 실제 전자기 해석 및 제조 승인은 구분합니다. 미검증 결과는 합격으로 간주하지 않습니다. 로터 타입의 목록 등록이 모든 형상군의 예측 정확도 검증을 의미하지 않습니다. 열·구조·스큐 해석은 현재 범위에서 제외하며 Flat 토크 리플 보완은 보류 상태입니다.

## 저장소에 포함하지 않는 데이터

`.gitignore`는 소스 관리의 초기 범위를 지정합니다. 원본 파일은 삭제하지 않습니다.

- `outputs/`, `validation/jobs/`: 누적 해석 결과, 기준 해석, 검토 패키지와 실행 이력.
- `material_library/`, `material_packages/`, `material_runs/`, `granta_runs/`, `granta_batches/`: 추출·정규화 재질 데이터와 실행 이력.
- Motor-CAD 모델·메시, 바이너리 압축 파일, 캐시, 로그와 자격증명 파일.

이 데이터는 별도로 백업해야 합니다. 실행 재현에 필요한 최소 기준 해석·소형 테스트 자료를 향후 선별해 추가할 수 있습니다. Ansys/Granta 및 제조사 데이터의 재배포 권한을 확인하기 전에는 업로드 대상에 포함하지 않습니다. 현재 소스에 별도의 오픈소스 라이선스를 자동 부여하지 않습니다.
