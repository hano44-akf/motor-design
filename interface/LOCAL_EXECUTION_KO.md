# 로컬 자동 설계 실행

PowerShell에서 `interface/launch.ps1`을 실행한 뒤 브라우저에서
<http://127.0.0.1:8765>를 엽니다. AI 서비스나 API 키는 사용하지 않습니다.
Python에는 `ansys-motorcad-core`가 설치되어 있어야 하며 Motor-CAD 및 유효한 라이선스가 필요합니다.

1. 상단 **실제 자동 설계**를 누릅니다.
2. **기존 12V 사양 불러오기**로 이전 요청을 입력하거나, 지원 범위 안에서 화면의 조건을 직접 지정합니다.
3. **현재 입력으로 자동 실행**을 누르면 전용 작업 폴더를 만들고 Python 작업을 시작합니다.
4. 진행 상태를 확인하고 **저장 결과 보기**로 실제 모델을 비교합니다.
5. `inputs.csv`, `results.csv`, `motorcad.csv`를 내려받습니다. Excel 한글 호환 UTF-8 BOM 형식입니다.

## 첫 연결 버전의 실행 범위

- POSCO 50PN470 / JL MAG N48UH 각각 단독 선택
- 방사형 자속 SPM, 4극 12슬롯, Delta, 1가닥·1병렬
- 자석 형상 Radial / Parallel / Breadloaf와 착자 Radial / Parallel을 독립 적용
- FOC Id=0 / SVPWM, 이상 인버터, 기계 손실 0 W
- 운전점 하나: 양수 토크·RPM 필수, 효율·전류밀도·리플·DC 전류 상한은 공란이면 목표에서 제외
- 입력한 기준·최소·최대 온도를 각각 부품의 동일 온도로 적용
- 입력한 DC 최소·정격·최대 전압에서 같은 운전점 검증
- 외경 55~100 mm, 적층 20~65 mm, 코일당 턴수 1~8, 나선경 0.8~2.2 mm: 자동·고정·범위 지원
- 나머지 형상은 외경에 따라 기준 형상을 비례 조정하며, 자석 극호는 전기각 120° 고정

지원하지 않는 입력을 지정하면 실행 전에 알려줍니다. 재질 후보군 전체·여러 운전점·다른 극슬롯·다른 결선·가닥수·제어 방식의 일반화는 후속 개발 범위입니다.

## 실행 내용과 결과 해석

형상·착자별 기준 해석 → 수식 탐색 → 서로 다른 후보 최대 3개 선정 → 전류 보정 →
정밀 해석 → 필요한 토크 보정 → 입력 온도·전압별 해석 → 부족분·결과 저장 순서입니다.
최대 2회 탐색을 기본값으로 사용합니다. 실행마다 새 기준 해석을 수행하므로 서로 다른 형상/착자의 보정값을 혼용하지 않습니다.

`target_met`: 현재 수치 검사와 요구조건을 모두 만족한 후보가 있습니다.
`best_effort`: 수치 검사를 통과했으나 요구조건이 부족한 후보를 반환했습니다.
`no_screened_candidate`: 전압·형상 등 수치 검사를 모두 통과한 후보가 없습니다. 진단용 결과를 보존합니다.

추가 기본 조건: 스위칭 주파수 공란 10 kHz, 토크 리플 상한 공란 20%, 허용 PWM 전류 리플 공란 15%(기준 운전점의 권선 상전류 기본파 RMS 대비 ΔIpp)입니다. 실제 PWM 전류 파형은 아직 검증하지 않으므로, 계산 가능한 목표만 만족한 후보는 `verification_incomplete`로 구분합니다. 허용 App를 계산했다는 사실을 실제 리플 만족으로 취급하지 않습니다.

전압은 고조파 보정 추정과 여유를 사용해 초기 탐색에서 검사하고,
해석 후 선간 피크 ≤ DC 전압, 보수적인 RMS 한도 및 Motor-CAD 전압 경고를 확인합니다.
이 검사는 실제 스위칭 회로·Delta 순환전류의 구동 가능성을 보증하지 않습니다.
50PN470의 50/60 Hz 외 철손은 외삽이며, 온도는 열평형 예측이 아닙니다.
현재 결과는 제조 검증이나 메시 수렴 검증을 마친 제품 설계가 아닙니다.

## 중지 및 재개

중지 요청은 현재 해석이 끝난 뒤 적용됩니다. 해석 중간 저장 파일을 강제로 종료하지 않습니다.
프로그램을 다시 실행할 때 다음 명령으로 완료된 동일 입력·해상도의 해석을 재사용할 수 있습니다.

```powershell
& 'C:/Users/jo061/AppData/Local/Python/pythoncore-3.14-64/python.exe' validation/design_job.py --resume validation/jobs/작업ID
```

입력이나 해상도가 다른 캐시는 재사용하지 않습니다. 같은 이름의 해석을 다시 수행하면 이전 모델·CSV·JSON을 `history`에 보존합니다.
작업별 입력, 예측값, 설정 읽기 확인값, 실제 해석값, 판정, 시간 및 로그는 `validation/jobs/작업ID`에 저장됩니다.

브라우저를 닫아도 서버와 작업 프로세스가 살아 있으면 계산은 계속됩니다. 컴퓨터 종료·절전 이후의 자동 재개는 제공하지 않습니다.
